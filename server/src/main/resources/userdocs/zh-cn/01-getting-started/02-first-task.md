# 创建你的第一个同步任务

> 文档最近代码对齐：2026-07-24。

本文以“源端业务表同步到 Doris”为例，说明最常用的新建任务流程。

## 前置检查

| 检查项 | 入口 | 通过标准 |
| --- | --- | --- |
| 源端连接 | 数据源管理 → 源端数据源 | 连接测试成功，可以列出 schema/table |
| 目标端连接 | 数据源管理 → 目标端数据源 | FE、HTTP 端口可用，目标库存在 |
| 源表字段 | 新建任务 → 选择视图与映射 | 字段能正常加载，没有大小写冲突 |
| 目标建表 | 新建任务 → 字段映射预览 | Doris 类型推荐没有 FAIL |

## Step 1：选择数据源

进入「同步任务管理 → 新建任务」。

需要选择：

- 源数据源；
- 源 Schema；
- 源表、视图或自定义 SQL；
- 目标 Doris 数据源；
- 任务分组。

如果选择视图，页面会显示视图档位。复杂视图可能只适合全量同步或只适合 ROW_COUNT 校验。

## Step 2：选择视图与映射

系统会自动读取源端字段，并生成 Doris 字段名和类型建议。

重点检查：

| 配置 | 说明 |
| --- | --- |
| 字段是否勾选 | 未勾选字段不会进入目标表 |
| 源字段类型 | 大文本、JSON、时间、decimal 要重点看推荐 Doris 类型 |
| 目标字段名 | 默认转小写，避免 Doris 字段大小写漂移 |
| 分片字段 | 小表不需要；大表只有存在合适主键或自增 ID 时才配置 |

## Step 3：同步策略

优先从四种模板中选一种：

| 模板 | 适用场景 | 关键配置 |
| --- | --- | --- |
| 全量同步 | 字典表、小维表、初始化 | 无增量字段 |
| 全量 + 增量 | 绝大多数业务主表 | 增量字段、Upsert 匹配键 |
| 仅增量 / 追加 | 日志、流水、事件表 | 增量字段 |
| 自定义窗口 | 补数、修数、一次性窗口同步 | 窗口起点、窗口终点 |

页面会展示“实际执行预览”。保存前重点确认：

- `partition_column` 是否符合预期；
- Reader 实际并发是否为 1 或指定并发；
- 写入语义是清空写入、追加还是 Upsert；
- 校验方式是否符合数据敏感度。

## Step 4：确认并发布

确认页会展示任务配置摘要。

建议第一次创建时：

1. 先保存为草稿；
2. 手动运行一次；
3. 查看执行历史、读写行数和错误日志；
4. 校验通过后再启用调度。

## 首次运行后检查

| 检查项 | 正常情况 | 异常处理 |
| --- | --- | --- |
| 任务状态 | SUCCESS | 查看执行日志和 SeaTunnel 错误摘要 |
| 读写行数 | 接近或一致 | 如果读数成倍放大，检查是否误配置并发/分片 |
| Doris 写入 | failed_rows = 0 | 查看脏数据和 Doris load error |
| 校验 | PASS | 按“同步失败排查流程”定位 |
| 水位线 | 成功后推进 | 失败时不应推进 |
